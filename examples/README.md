# Ejemplos sintéticos

Recorridos inventados para ver cómo se encadenan las features. No son pacientes, no son consejos de tratamiento y no salen de un expediente real.

Los nombres, los números y las citas están escritos para ilustrar el flujo. Una cita nombrada aquí no es una recuperación real del sistema.

| Ejemplo | Qué recorre |
|---|---|
| [Expediente, alerta y validación](expediente-alerta-validacion.md) | Historia, laboratorio, alerta determinista, propuesta que espera |
| [Pregunta con evidencia y protocolo](pregunta-evidencia-protocolo.md) | Rapid, fuentes, gobernanza y lo que no entra al chart |
| [Seguimiento entre visitas](seguimiento-entre-visitas.md) | Nota, tarjeta de check-in, silencio en la bandeja, promoción manual |
